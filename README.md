# Verify-AI
An AI-assisted product verification platform designed to help consumers identify potentially counterfeit products through image scanning and product information analysis

## Problem Statement
Consumers struggle to distinguish genuine
products from counterfeit alternatives.

## Objectives
- Analyse product information.
- Extract information from product images.
- Identify inconsistencies.
- Generate evidence-based reports.

## Technologies
- Python
- Pandas
- SQL
- Machine Learning
- OCR

## Project Status
Currently in development.
